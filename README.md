## Ambiente Conda

Com o Conda ou o Miniforge instalado, ative o ambiente do projeto para rodar localmente:

```bash
conda activate atividade-folium
```

Inicie o aplicativo localmente com:

```bash
streamlit run streamlit_app.py
```
